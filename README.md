# 跨市场每日复盘看板（接入准备版）

## 已同步的需求
- 覆盖 A 股、港股、美股；盘中监控与收盘复盘的操作入口保留。
- 原始 15 个序列完整保留，每个序列有字段、展示区块、推荐数据来源。
- 保留科创50（000688）展示位。
- A 股配色按红涨绿跌处理。
- 页面明确区分“方案/待接入”与真实数据，不以演示时间冒充行情更新时间。
- 提供本地后端代理的行情连通性测试入口。

## 启动
需要安装 Python 3.9 或更新版本，无需安装第三方包。

```bash
cd cross_market_dashboard_project
python3 server.py
```

浏览器打开： http://127.0.0.1:8765

健康检查： http://127.0.0.1:8765/api/health
行情测试：页面输入代码后点击“查询行情”，或访问 `/api/quote?code=sh000688`。

常见代码格式（需由上游实际验证）：
- A 股/指数示例：`sh000001`、`sh000688`
- 港股示例：`hk00700`
- 美股示例：`usAAPL`

## 数据源和边界
默认代理到 `https://api.ashareapi.com/v1/quote?code=...`，该服务商文档描述了跨市场轻量行情接口。当前代码只是提供可运行的连接测试/代理层，**不保证所有指数代码均受支持，也没有将行情自动填入所有看板卡片**。首次运行需实际测试接口返回、延迟、覆盖、限额和使用许可；若不适用，可设置 `QUOTE_API_BASE` 指向你有权限使用的供应商端点。

```bash
QUOTE_API_BASE='https://your-provider.example/quote' python3 server.py
```

如供应商需要密钥，请在后端增加认证逻辑并从环境变量读取；不要把密钥写进 `index.html`、公开仓库或聊天记录。不要在未经确认的情况下将公开演示接口用于生产、商业展示或再分发。
